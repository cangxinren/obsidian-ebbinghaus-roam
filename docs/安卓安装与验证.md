# Ebbinghaus Roam 安卓安装与验证

## 插件形态

这是 **Obsidian 社区插件**，不是独立安卓 App。它依赖 Obsidian 的笔记库 API，正确用法是把插件目录放进手机 vault 的 `.obsidian/plugins/`，然后在安卓 Obsidian 里启用。

当前插件已按手机端适配：

- 单文件 `main.js`，无相对 `require`，桌面/安卓都能加载；
- 无状态栏时自动跳过；
- 无右侧栏时用 `getLeaf('tab')` 打开发面板；
- 确认框使用 Obsidian `Modal`，不依赖 `window.confirm`；
- 手机端导出写入库根目录，导入从库根目录的备份文件中选择；
- 触控按钮最小高度 36px。

## 在 VSCode 里验证

1. 用 VSCode 打开本目录：

   ```
   /home/GCMG/my_project/ebbinghaus-roam-dev
   ```

   Windows 版 VSCode 可通过 WSL 扩展打开；本机 WSL 未把 `code` 命令加入 PATH，不依赖它。

2. 终端运行：

   ```bash
   node verify.js
   ```

   或按 `Ctrl+Shift+B` 运行默认任务 `verify`。

   检查内容：
   - `main.js` 语法；
   - `manifest.json` 字段（`isDesktopOnly === false` 等）；
   - 安卓兼容静态扫描（只允许 `require('obsidian')`、存在 `Platform.isMobile`、`getLeaf('tab')`、`SuggestModal`）；
   - 调度逻辑测试 26 项；
   - 插件集成测试 22 项。

3. 生成安卓安装包：

   ```bash
   node build.js
   ```

   或运行任务 `package:android`。

   产物：

   ```
   dist/
     ebbinghaus-roam/
       manifest.json
       main.js
       styles.css
       package.json
     ebbinghaus-roam-<version>.zip
     安卓安装说明.md
   ```

   `data.json` 不会被打包，避免把个人复习进度带进安装包。

## 手机安装

### 方式一：remotely-save 同步（你的当前方式）

1. 桌面端 Obsidian → remotely-save 设置，确认同步范围包含 `.obsidian`（配置文件夹/插件）。
2. 手动触发一次同步。
3. 手机端 Obsidian 打开同一个库，执行 remotely-save 拉取。
4. 确认手机 vault 中出现：

   ```
   .obsidian/plugins/ebbinghaus-roam/manifest.json
   ```

> 如果 remotely-save 没有同步 `.obsidian`，插件不会自动出现，请用方式二。

### 方式二：手动放置（兜底）

1. 把 `dist/ebbinghaus-roam-<version>.zip` 传到手机（数据线、网盘、聊天工具均可）。
2. 解压得到 `ebbinghaus-roam/` 文件夹。
3. 复制到手机 vault 的 `.obsidian/plugins/`，最终为：

   ```
   .obsidian/plugins/ebbinghaus-roam/manifest.json
   ```

4. 完全退出 Obsidian，再重新打开。

> Android 11+ 若无法直接访问 `Android/data/md.obsidian`，可先把 zip 放进 vault 根目录，在手机文件管理器里解压，再把文件夹移动到 `.obsidian/plugins/`。

## 手机端启用

Obsidian → 设置 → 社区插件 → 关闭受限模式 → 刷新 → 启用「Ebbinghaus Roam 漫游复习」。

要求 Obsidian 版本 ≥ 1.5.0。

## 数据与同步

- 复习进度主文件：**附件目录**的 `附件/ebbinghaus-roam-data.json`，随 remotely-save 同步，桌面与手机共用同一份数据。
- **实时双向更新，不需要导入导出**：
  - 本端每次评分、自动晋级、改设置都会在 1 秒内写回该文件；
  - 另一端（remotely-save 拉取后）文件变化会被插件监听到，自动逐条按 `updatedAt` 合并，lastOpen 取较大值；
  - 本地有更新记录时会自动回写一次，使两端收敛；
  - 另有 20 秒轮询兜底，防止某些平台不触发文件变更事件。
- 导入导出按钮保留，仅用于手动备份或迁移，日常不需要。
- 插件目录的 `data.json` 仅用于旧数据迁移，v1.5.0 起不再更新。
- 推荐的首次同步顺序：
  1. 桌面端重载插件 v1.5.0；
  2. 等 1–2 秒，确认附件目录生成 `ebbinghaus-roam-data.json`；
  3. 触发 remotely-save 同步；
  4. 手机端拉取；
  5. 手机端重载插件。
- 两端同时修改可能产生 `*.sync-conflict-*.json`；保留最新的一份并重命名为 `ebbinghaus-roam-data.json`。
- 插件只读写自己的数据文件，不修改笔记内容或 frontmatter。
- 手机端首次启用会扫描全库并写入记录，数千篇时可能停顿几秒，属正常。

## 常见问题

**插件列表里看不到插件**

- 确认路径是 `.obsidian/plugins/ebbinghaus-roam/manifest.json`，不是多套一层文件夹。
- 确认已关闭受限模式，并点过「刷新」。
- 完全退出 Obsidian 再打开。

**点击按钮没有打开笔记**

- 确认点的是左侧书本图标（左键直接开始漫游），不是只打开面板。
- 如果弹出「打开失败：…」，把提示内容记录下来排查。
- 也可在命令面板搜索「开始漫游」执行，和按钮走同一条打开逻辑。

**手机端没有状态栏**

正常。手机端通过左侧书本图标或命令面板使用，面板里也有完整控制。
